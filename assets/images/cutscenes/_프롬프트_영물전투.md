# 영물 전투 컷씬 — 이미지 프롬프트

> 사양: docs/20 §③ 영물 전투 컷씬. **다상태 보스전 시퀀스**(조우→전투중→승/패/도망).
> 원칙(엄수):
> - **제자 신체 프레임 밖**(뒷모습·실루엣·손도 금지) — 파티 무작위·성별/복장 갈림. **1인칭 시점**으로 영물을 마주본 구도.
> - **영물(NPC 야수)은 주인공** — 정면·크게. 영물·영기·풍경이 화면을 채운다.
> - 화풍 **수묵+담채**(먹빛 베이스 + 속성 시그니처 한 색). 세로 **9:16**. 화면에 글자·낙관 금지(한자는 앱이 얹음).
> - **안전선**: 영물의 머리·핵심은 세로 중앙 ±1/3 · 가로 중앙 ±1/3 안(태블릿 위아래·폰 좌우 잘림 대비). 잘림 0.

## 공용 상태 컷 (영물 무관 — 3컷)

### beast-fight (전투 중 · 鬪 · blood)
```
세로 9:16 수묵담채 무협 일러스트. 1인칭 시점: 거대한 영물과 맞부딪는 한순간. 화면 가득 짐승의 발톱과 기파, 튀어오르는 흙먼지와 먹빛 기운. 사람의 몸은 화면에 없음(시점 주인공의 손·무기도 보이지 않게). 격렬한 운동감, 붉은 핏기 한 점. 중앙 1/3에 충돌 지점. 글자 없음.
```

### beast-defeat (패배 · 敗 · blood)
```
세로 9:16 수묵담채 무협 일러스트. 1인칭 시점: 영물에게 압도당해 흐려지는 시야. 위에서 짓누르는 거대한 그림자, 화면 가장자리로 번지는 붉은 핏빛과 어둠. 사람의 몸은 보이지 않음. 사경(死境)의 긴박함과 무력감. 중앙에 영물의 위압적 실루엣. 글자 없음.
```

### beast-flee (도망 · 退 · ink)
```
세로 9:16 수묵담채 무협 일러스트. 1인칭 시점: 영물을 등지고 물러나는 산길. 화면 앞으로 멀어지는 안갯속 산길, 뒤편(상단)으로 점점 작아지는 영물의 그림자. 사람의 몸은 없음. 빈손으로 돌아서는 씁쓸함, 차분한 먹빛. 글자 없음.
```

## 영물별 컷 (조우·승리 — 4종 × 2 = 8컷)

> 각 영물의 **조우(遭遇·遇)**: 영기 속에서 모습을 드러내 이쪽을 노려보는 1인칭 구도.
> 각 영물의 **승리(捷·獲)**: 쓰러진 영물 곁에 영롱하게 빛나는 정수/신품초(gold 결).

### 영산의 주인(靈山之主) — 영산 절지 · 영기/무
- 조우: `영기 자욱한 금단의 땅, 안개 속에서 거대하고 고고한 태고의 영물이 천천히 모습을 드러내 이쪽을 응시한다. 신비로운 흰 영기, 푸른 빛 한 줄기. 1인칭 시점.`
- 승리: `쓰러진 태고의 영물, 그 곁에 영롱하게 빛나는 영물 정수(구슬 같은 영단)와 신품 영초. 금빛 서기(瑞氣). 1인칭 시점.`

### 묵린혈망(墨鱗血蟒) — 독곡 · 독/혈
- 조우: `독무 자욱한 골짜기, 검은 비늘의 거대한 혈망(붉은 무늬 구렁이)이 머리를 치켜들고 독기를 뿜으며 노려본다. 먹빛 비늘 + 핏빛 무늬. 1인칭 시점.`
- 승리: `쓰러진 검은 혈망 곁에 빛나는 혈망 독정(붉은 결정). 금빛 서기. 1인칭 시점.`

### 현빙 영물(玄氷靈物) — 설산 · 냉/빙
- 조우: `혹한의 설산, 푸르스름한 얼음 기운을 두른 거대한 영물이 눈보라 속에서 모습을 드러낸다. 먹빛 + 시린 청백색. 1인칭 시점.`
- 승리: `쓰러진 얼음 영물 곁에 빛나는 현빙 정수(투명한 푸른 결정). 금빛 서기. 1인칭 시점.`

### 만년화리(萬年火鯉) — 화산 · 화/염
- 조우: `열기 가득한 화산 지대, 불꽃을 두른 거대한 화리(火鯉, 잉어 형상 영물)가 용암 위로 솟구쳐 이쪽을 향한다. 먹빛 + 타오르는 주홍. 1인칭 시점.`
- 승리: `쓰러진 화리 곁에 빛나는 화린 정수(붉게 타는 결정). 금빛 서기. 1인칭 시점.`

> 그림 없는 동안은 그레이박스(한자+톤+dashed 그림 자리)로 시퀀스가 그대로 작동(docs/20).
