# independent-verify — 문서기반 독립 검증 (허위 오라클 회피)

기존 시뮬 로직과 **분리된 시각**으로, **문서만 보고**(코드 의도 미참조) 불변식을 도출해 측정 도구를
처음부터 짜고 엔진 실제 출력과 대조한다. 코드를 베낀 오라클은 코드와 같이 틀린다(허위 오라클).
**문서-코드 drift**와 **오라클 사각**을 잡는다. 방법: docs/43 + docs/37 Part D/E.

## 언제
- 시스템이 성숙해 "기존 시뮬이 코드와 같이 틀렸을 수도" 있을 때.
- "전 계약 PASS"·"0 위반"을 의심할 때 — 검사기 자신을 의심해야 할 때.
- 릴리즈 전 문서-코드 일치를 한 번 훑을 때.

## 실행 (에이전트 스폰)
`Agent`(general-purpose)로 독립 세션을 띄운다. 역할·골격 = `.claude/.agents/independent-verifier.md`:

> "너는 사도전의 독립 검증 세션이다. 목표: **문서만 보고**(docs/35·37 등, 코드 의도 베끼지 말고) [범위]의
> 불변식을 도출해 `scripts/sim`에 측정 도구를 새로 짜고 엔진 실제 출력과 대조, **문서-코드 불일치·오라클
> 사각**을 찾는다. 원칙: ①문서서 도출(`src/systems`·`src/engine` 로직 베끼기 금지) ②모든 체크 A/B 자가검증
> (틀린 입력에 반드시 실패) ③추측 금지·시뮬로 확인(표본 충분)·소스 수정 금지(보고만)·git 금지 ④재현 가능
> (시드+입력). 러너: `npx tsx scripts/sim/_dv_X.ts` 또는 `node scripts/sim/_run.cjs ...`(RN import 시).
> 보고: 불변식 목록(출처 문서)/측정+표본/발견(file:line)/남긴 스크립트 경로."

- **whole-game 모드**: docs/37 케이스 레지스트리·시스템 문서에서 불변식 도출 + 스토어를 `__mocks__` 위에서
  구동해 악질/원숭이 난사(fuzz-game과 결합).

## 규칙 (반드시 스폰 프롬프트에 포함)
1. **문서에서 도출, 코드 의도 미참조** — "코드가 이러니 이걸 테스트"는 금지(같이 틀림).
2. **A/B 자가검증** — 모든 체크는 일부러 깬 입력에 반드시 실패함을 증명한 것만 신뢰.
3. **추측 금지** — 시뮬로 확인(표본 N≥1만 또는 풀시뮬 표본 명기). 소스 수정 금지(보고만).
4. **git 커밋/add 금지**(다른 세션이 같은 레포 공유). 하네스는 `scripts/sim/_dv_*`로 남기고 경로 보고.
5. **재현 가능** — 실패는 시드+입력으로 재현.

## 결과 처리 (메인 세션)
drift/사각/위반 보고 → docs/37 운용 룰 후속(재현·사각분석 Part D·등재 Part A·동종사냥·방법기록 docs/43).
허위 오라클이면 그 시뮬을 교정하고 A/B로 재검증. 수치 편차는 `statcheck`로 정량(docs/42).
