# fuzz-game — 악질/원숭이 전체게임 퍼징

케이스 시뮬(docs/37 Part A)이 못 잡는 **모르는 버그**를, 실제 사용자 진입점(zustand 스토어 액션·시스템
함수)을 무작위·적대적으로 난사해 찾는다. 방법론 = docs/43(사냥 5렌즈)·docs/37 Part D(사각). 케이스 등재 = docs/37.

## 왜 (케이스 시뮬의 사각 — docs/37 Part D)
케이스/감사는 보통 ① 상태 주입(실 호출경로 우회) ② 단일 시점 ③ valid 입력만 본다. 퍼징은 셋을 다 친다:
실 스토어를 직접 구동 + 장기 교차(회차 경계·재시작) + 적대 입력. 흡성대법(R36)·더블부킹(R16)·id충돌(R22)이
이런 부류였다.

## 실행
1. **불변식 확정** (docs/37 Part B 계약 + 코드): 유일성/단일점유(제자 더블부킹 0)·수량 경계(성 1~10·심마
   0~100·자금 ≥0)·게이트(미달 파견·음수 수량 거부)·결정론(같은 시드=같은 결과)·NaN/음수 0·진행 가능(소프트락 0).
2. **러너·모킹**: `npx tsx scripts/sim/X.ts`(RN-free) / `node scripts/sim/_run.cjs scripts/sim/X.ts`(RN 시스템
   import 시). 스토어/시스템을 import하면 `__mocks__/`(async-storage·executorch)가 자동 적용 — 추가 mock 필요 시 거기에.
3. **두 갈래로 난사**:
   - **악질(adversarial)**: 경계 악용(하한까지 줄인 뒤 또 줄이기·가득 찼는데 또 추가)·순서 꼬기(전제 전 종료/진행)·
     비정상 값(없는 id·음수·NaN·빈 문자열·거대값). 기존 본보기: `mindstate`·`relations`·`numextremes`·`alchemy`(음수수량)·`gamestate`(전방호환)·`woundstack`.
   - **원숭이(monkey)**: 전 액션 무작위 혼합 + 장기 진행으로 교차 시점 노출. 드라이버: `node .claude/skills/balance-sim/run-headless.cjs`(headless.ts `autoPlayRun` 랜덤 플레이) — 회차 경계·재시작까지 굴리려면 여러 시드로.
4. **여러 시드·길게**: 같은 하네스를 여러 시드로. 모드를 나눠 버그 격리(예: 자기 점유만 변이 vs 타 점유 허용).
5. **A/B 자가검증 필수**: 새 불변식 체크는 **일부러 깬 상태에서 반드시 실패**함을 증명한 것만 신뢰. 항상
   통과하는 체크는 허위 오라클 — 폐기. (clean 0위반 + 익스플로잇 검출, 둘 다 참)

## 5렌즈로 겨눈다 (docs/43 — 광맥 굵은 순)
① 시간차(발동↔해소 사이 상태변화) → ② 자원경합(하나를 둘이 점유) → ③ 생애경계(마지막 1명·재시작·졸업/하산 전이)
→ ④ 의미정합(보고만 미배선·낸 만큼만 효과) → ⑤ id충돌(같은 날·같은 지역·다른 파티). 앞쪽부터 시퀀스를 설계.

## 버그를 찾으면 (docs/37 운용 룰 — 고치고 끝내지 말 것)
1. 최소 재현 하네스(시드+입력)를 `scripts/sim/`에 남긴다.
2. **왜 기존 테스트가 못 잡았나** 규명(docs/37 Part D 사각 번호) → 등재.
3. docs/37 Part A에 `증상→원인→수정→재검증` 행 + 사각 닫는 시뮬 케이스 추가(A/B 검증). 수정 후 **좁은 repro뿐
   아니라 넓은 퍼저(여러 시드)** 재실행(불완전 수정의 변종 차단).
4. **동종 버그 사냥**: 그 렌즈를 코드 전체에 적용(잔존 0까지). 전투 결과 필드면 `testguard` manifest 분류.
5. 발견 **방법**이 docs/43에 없으면 추가.

## 원칙
- **추측 금지** — 깨지는지 실제로 돌려 확인(수천+ 시퀀스). 소스는 보고만, 수정은 사람 합의 후.
- 위반 시 도구를 느슨하게 풀지 않는다 — 엔진/스토어를 고친다(불변식이 기준).
- 하네스 보존(상시 재실행). 오래 걸리면 백그라운드로(폴링 금지).

A/B 결과. "docs/37·43에 기입했고 `test` 스킬로 회귀 배터리 돌리면 됩니다"로 인계.
